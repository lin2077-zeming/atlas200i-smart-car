### 2. 速度 / 转向标定 ✅（2026-10-28 真机实测重写，已闭环）

> 📘 **完整排查过程 + 可复制的标定流程**：[运动控制实测与标定](../5.整车联调/运动控制实测与标定.md)

**旧模型（已作废）** `V = 101.6×(cmd−18.6)`、`ω = 0.371×(cmd−138)`、斜坡 3.1 s
—— 建立在"速度命令值不是 mm/s"这一**错误前提**上的拟合，
导致落地时速度慢约 40 倍（"前进一米"实际只走 7 cm，肉眼像完全不动）。

**现模型（协议源码 + 遥控器基准 + 卷尺/量角器实测）**

| 量 | 实测结论 | 数据来源 |
|---|---|---|
| 平移速度 | **1 单位 = 1 mm/s**（协议本来就是 mm/s） | 协议注释 + 命令150→回传149 + 遥控"1米"∫vx=916mm |
| 平移死区 | **0**（命令 30 → 回传 30） | 回传实测 |
| 起步斜坡 | **0.8 s** | 遥控录制 vx 爬升曲线 |
| 转向角速度 | **42.7 °/s（Z=1600）** | 目测迭代 4 轮 + ∫vz 独立交叉验证 |
| 转向量程 | **±1600**，**与平移 ±500 不同** | 回传 vz 随 Z 增长；遥控 vz 可达 1505 |
| 距离补偿 | 后退 ×1.10 · 计划内连续步 ×1.15 | 卷尺实测 90 cm / 85 cm |
| 左右对称 | 差 **0.5%** | 左/右 180° 的 ∫vz（3879 / 3897） |

**关键数字**：90° = 2.11 s · 180° = 4.22 s · 360° = 8.43 s · 1 米@300 = 3.73 s
**档位**：慢/中/快 = **200 / 300 / 450 mm/s**（遥控"丝滑手感"实测 236~621 mm/s）

**本次修的 5 处**
1. 速度单位重写（慢 40 倍 → 正确恒等映射）
2. 转向钳位：`_clamp_speed` → 新增 `_clamp_turn`（三处）；
   其中 `parse_text_command` 的**钳位发生在判断动作之前**，会把 1600 悄悄砍成 500
3. `duration_for_angle` 上限 8 s → **12 s**（否则一圈 8.43 s 永远走不满）
4. 新增 `BACKWARD_GAIN` / `PLAN_MOVE_GAIN` 两个实测补偿
5. 新增 `distance_efficiency()` 唯一口径 —— 防止补偿一加、自检脚本假绿

**真机验证**：单条前进 1 米 = **100 cm** ✅ · 90° 正准 ✅ · 360° ≈355~370° ·
演示路线三步顺序与距离达标 · 安全链路 10/10 · 语音链路 5/5

**标定工具**：`record_feedback.py`（录回传）· `analyze_remote.py`（分段积分）·
`verify_presets.py`（离线自检）· `bench_web.sh`（21 项架空验收）

2. 用 `kws_batch_test.py --sweep` 重扫阈值，平衡召回与误触发

### 6. 语音唤醒 ✅（部分验证）

**已做**

- 唤醒期间**语音急停会短暂失效 5~6 秒**（麦克风独占，硬件限制）

### 7. TTS 语音合成 ✅✅

**已做**
- **NPU TTS**（FastSpeech2 + HiFiGAN）：RTF **0.92**，比 Kokoro CPU 快 **5.89×**
- 句子切分、**单段 ≤12 汉字**（实测硬上限）、数字/单位中文读法
- 输出到网络音箱（板子无喇叭）

**已穷尽的优化（别重复投入）**
- 段间停顿 ≈ `段数 × 1.07~1.12s − 音频时长`，**不可消除**
- 已试过并否定：裁剪静音、流水线预合成（CPU 争抢反而更慢）、`max_mel_len` 300（3 倍慢）/400/500（段错误）、放宽 `DEFAULT_SENT_LEN`
- **唯一有效杠杆**：减少段数 → LLM 话术 ≤12 字

### 8. LLM 接入 ✅✅

**已做**
- 云端 **glm-4-flash**（主）；本地 server/cli（备，走 GBNF 语法）
- **幻觉闸门三件套**：动作白名单 + **关键词证据检查** + 置信度阈值（实测把误判从 9 降到 0）
- 防复读、`say` ≤12 字服务端封顶、缓存
- **多步 `steps` 支持**（仅云端模式）

**实测**：单步/闲聊真 A/B **10/10 零回归**；多步正反例全部正确；注入 `stop` 步被白名单挡掉

**遗留**
- 本地 GBNF 模式**不支持多步**（只执行第一个动作，属改动前既有行为）
- 云端偶发漏填 `confidence`（1/6）→ 按安全侧丢弃

### 9. 多步指令规划器 ✅✅

**已做**
- 两条入口：规则层 `parse_plan()`（再/然后/接着/之后/随后/;）+ LLM `LlmReply.steps`
- 限额：步数 ≤3、单步距离 ≤1000mm、单步角度 ≤90°（**只对多步生效**）
- 每步仍走 `_do_action()` 统一入口，安全闸门不绕开
- **急停可中断**（`_plan_abort`）、中止后**不自动续跑**、**重入保护**（执行中再来多步直接拒绝）
- 修 B2：限幅改向下取整，杜绝 1002.25mm / 90.87° 超限

**真机验证**
- 顺序执行 ✅、急停中断 ✅（第 3 步从未下发）、锁定态拒绝 ✅
- **「先前进半米，再左转30度」→ 前进 → 停 → 左转约 30°** ✅

**遗留**
- 计划执行中再来一条**单步**指令会互相覆盖（未做 supersede）
- 4 步以上 = 执行前 3 步 + 忽略后续（不是整体拒绝）
