## 一、在开发板上安装 Tailscale

### 安装

```Bash
curl -fsSL https://tailscale.com/install.sh | sh
```

### 启动并登录

```Bash
tailscale up --ssh
```

执行后会输出一个授权链接，在浏览器打开并登录 Tailscale 账号即可。

### 查看状态

```Bash
tailscale status          # 查看所有设备
tailscale ip -4           # 查看本机 Tailscale IP
tailscale netcheck        # 网络环境诊断
```

### 设置开机自启（默认已启用）

```Bash
systemctl enable tailscaled
systemctl status tailscaled
```

## 二、在其他设备上安装 Tailscale

### Windows

1. 访问 [https://tailscale\.com/download/windows](https://tailscale.com/download/windows)

2. 下载并安装

3. 右下角托盘点击 Tailscale 图标 → 登录

4. 用**同一个账号**登录

### macOS

```Bash
brew install --cask tailscale
```

或访问 [https://tailscale\.com/download](https://tailscale.com/download) 下载

### Linux

```Bash
curl -fsSL https://tailscale.com/install.sh | sh
tailscale up
```

## 三、设备共享（让别人也能连接开发板）

### 方式一：共享到别人的 Tailscale 账号（推荐）

> 别人需要先注册自己的 Tailscale 账号（免费），此方式不会暴露你的其他设备。
> 
>

> **注意**：共享后对方只能访问这台开发板，无法看到你账号下的其他设备（如笔记本等）。

> 

### 方式二：共用账号（简单但不够安全）

把 Tailscale 账号密码给对方，他在自己电脑登录同一个账号即可。

> **风险**：对方能看到你所有绑定了该账号的设备，包括你的笔记本等。

## 四、延迟优化（可选）

### 优化方案

### 自建 DERP 简要步骤

1. 购买一台大陆云服务器（阿里云/腾讯云轻量应用服务器，Ubuntu 22\.04）

2. 开放端口 `3478/udp` 和 `443/tcp`

3. 安装 derper：

```Bash
# 在 VPS 上执行
apt install -y golang
go install tailscale.com/cmd/derper@latest
derper -hostname=你的VPS公网IP -c derper.conf
```

4. 在开发板上配置自定义 DERP：

```Bash
tailscale up --accept-dns=false --accept-routes
# 编辑 ACL 策略，在 Tailscale admin 面板中配置自定义 DERP 节点
```

## 五、常见问题

### Q: `ssh root@100.105.206.66` 连不上？

**可能原因**：

1. 笔记本 Tailscale 客户端未登录或已退出

2. 开发板 `tailscaled` 服务未运行 → `systemctl start tailscaled`

3. 校园网 UDP 被临时封锁 → 等待 DERP 中继自动切换

4. 开发板掉网了（热点或校园 WiFi 断连）

**排查**：

```Bash
tailscale status          # 看看设备是否在线
tailscale netcheck        # 检查 UDP 和 DERP 状态
systemctl status tailscaled  # 检查服务状态
```

### Q: 延迟太大怎么办？

海外中继固有延迟，如果严重影响使用，考虑两个方向：

1. **自建境内 DERP**：延迟降到 30ms 以内

2. **frp 替代 Tailscale**：走纯 TCP，国内 VPS 转发，延迟更低

### Q: 每次重启都需要重新配置吗？

不需要。`tailscaled` 是系统服务，开机自启；`tailscale up` 只需执行一次登录即可。

### Q: `tailscale up` 显示 URL 但无法复制？

可以访问 `https://login.tailscale.com/admin/machines` 手动添加，或使用 `tailscale login` 重新获取登录链接。
