# 找小车 IP 的小工具

板子的 IP 由路由器 DHCP 分配，**会变**。这两个脚本负责把它找出来。

| 文件 | 在哪跑 | 干什么 |
|---|---|---|
| `find_car.cmd` | **Windows（双击）** | 找出小车 IP，给出 SSH 命令 |
| `find_car.ps1` | Windows（命令行） | 同上，可带参数 |
| `find_ip.sh` | **板子上** | 板子查自己的 IP（**最可靠**） |

---

## 最简用法

**在电脑上：**

```powershell
cd .
.\find_car.cmd
```

或者直接双击 `find_car.cmd`。

**在板子上**（板子有屏幕时，这是最准的办法）：

```bash
bash find_ip.sh          # 必须用 bash（脚本用了 mapfile 等 bash 特性）
bash find_ip.sh --ssh    # 只吐 IP，便于脚本取值
```

---

## `find_car.ps1` 参数

| 参数 | 说明 |
|---|---|
| `-Subnet 192.168.31` | 指定要扫的网段（默认自动从本机 IPv4 推断，优先 WLAN） |
| `-Sweep` | 强制 ping 扫描全网段（默认只在前面几级都没命中时才扫） |
| `-NoProbe` | 跳过 SSH 复核，只按 MAC 找（快很多） |
| `-TimeoutMs 900` | ping 超时 |

例子：

```powershell
.\find_car.ps1 -Subnet 192.168.31 -Sweep
.\find_car.ps1 -NoProbe
```

---

## 它是怎么找的

**核心思路：认 MAC，不认 IP。**

板子有两块网卡，MAC 前缀固定：

| 接口 | MAC 前缀 | 用途 |
|---|---|---|
| `wlan0` | **`ac:45:ef`** | AX210 WiFi（主用） |
| `eth0` / `eth1` | **`a0:70:b7`** | 华为板载网卡（网线 ICS） |

流程（逐级 fallback，任一级命中就停）：

1. **已知/历史 IP 直连测试** —— 网线 ICS 固定 `192.168.137.100`；上次的 WiFi 地址
2. **本机 ARP 缓存** —— 按 MAC 前缀捞
3. **目标网段的 ARP 缓存** —— 同上
4. **并行 ping 扫 `x.x.x.1-254`** —— 填充 ARP 后再捞（最慢，兜底）

最后用 SSH 复核（能连上说明确实是那台 Linux 板子）。

---

## ⚠️ 一个踩过的坑

**ARP 缓存会过期，扫描一次没找到 ≠ 板子没联网。**

实测踩到过：扫了 21 台设备都没找到板子，差点误判"板子没连上 WiFi"，
后来插上网线一查才发现它好好地连在 `192.168.31.128`。

所以：

- 第一次没找到，**加 `-Sweep` 再试一次**（会强制刷新 ARP）
- 还找不到，**直接在板子上跑 `bash find_ip.sh`**（有屏幕的话，这是最准的）
- 或者插网线走固定地址 `ssh root@192.168.137.100`

---

## 让 IP 固定下来（推荐）

去路由器管理页（本项目是 **`http://192.168.31.1`**）→ 高级设置 → **DHCP 静态 IP 绑定**：

| 字段 | 值 |
|---|---|
| MAC 地址 | **`ac:45:ef:a6:36:c3`**（板子 WiFi 网卡） |
| 绑定 IP | **`192.168.31.128`** |
| 备注 | `davinci-mini` |

绑好后 `ssh root@192.168.31.128` 就永远有效，不用再找。

## 相关：板子的网络配置现状

| 项 | 值 |
|---|---|
| SSID | `A102` |
| 板子 WiFi IP | `192.168.31.128` |
| 板子网线 IP | `192.168.137.100`（PC 的 ICS 静态） |
| WiFi 优先级 | `A102`=100，旧热点 `HONOR 200`=10（备用） |
| 开机自动连 | ✅ 已修（原先 `permissions: user:HwHiAiUser` 导致**必须登录桌面才连**）|

### 🚗 小车远程控制台（2026-10-27 新增）

| 文件 | 作用 |
|---|---|
| `启动小车控制台.cmd` | **双击即用**：自动找板子 → SSH 启动 Web 控制台 → 打开浏览器 |
| `car_console.ps1` | 上面的实际逻辑；支持 `-Stop` / `-Sweep` / `-IP` / `-Asr` |

它解决的是"不想在板子上敲命令"：串口独占，Web 服务必须和控制器同进程，
所以由脚本替你 SSH 上去拉起。找板子顺序：上次缓存 → mDNS `davinci-mini.local`
→ 已知 IP（192.168.137.100 / 192.168.31.128 / 10.36.121.127）→ `-Sweep` 扫网段。

详见《[远程 Web 控制台](../远程Web控制台.md)》。
