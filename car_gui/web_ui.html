还差三步就能开动

现在还没找到小车，插好线会自动连上，不用刷新页面。

  1. 接串口 小车的 USB 线插到板子的 USB 口
  2. 上电 先开小车电池，再确认板子已启动
  3. 等它自己连 3 秒内状态条会变成「已连接」

等不及了？先在「⚙ 高级」里打开「离线演示」，页面照样能点。
